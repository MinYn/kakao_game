## 모든 발화로 설정 (권장) ⭐

### 목표

**게임봇 메인 블록**에 모든 사용자 메시지를 연결하여 스킬 서버로 전달하는 것

### 화면에서 확인할 요소

**"사용자 발화" 섹션**:
- 제목: "사용자 발화" (물음표 아이콘 옆)
- 입력 필드: "사용자가 입력할 것 같은 대표적인 발화를 입력해주세요"
- 발화 패턴 목록: 체크박스와 발화 패턴이 표시되는 영역
- "모든 발화" 옵션: 체크박스 또는 토글 (있는 경우)

### 단계별 설정

#### 1단계: 발화 패턴 확인

1. **"사용자 발화"** 섹션 확인
2. 현재 등록된 발화 패턴 확인
   - 발화 패턴이 있다면 모두 삭제 필요

#### 2단계: 발화 패턴 삭제 (있는 경우)

1. 발화 패턴 목록에서 각 발화 패턴 옆의 **삭제 버튼** 클릭
2. 또는 발화 패턴 체크박스 선택 후 **일괄 삭제**
3. 모든 발화 패턴 삭제 완료

#### 3단계: 모든 발화 활성화

**옵션 A: "모든 발화" 체크박스/토글이 있는 경우**

1. 발화 패턴 목록 아래에 있는 **"모든 발화"** 체크박스 확인
2. **체크박스 활성화** ✅
3. 저장

**옵션 B: "모든 발화" 옵션이 없는 경우**

1. 발화 패턴 입력 필드를 **비워두기**
2. 발화 패턴을 **추가하지 않기**
3. 저장
4. 이렇게 하면 자동으로 모든 발화가 이 블록으로 연결됨

**옵션 C: 기본 블록으로 설정**

1. 블록 설정에서 **"기본 블록"** 또는 **"기본 응답 블록"** 옵션 선택
2. 이렇게 하면 다른 블록과 매칭되지 않는 모든 발화가 이 블록으로 연결됨

### 확인 방법

**설정이 올바른지 확인**:

✅ **올바른 설정**:
- 발화 패턴 목록이 비어있음
- 또는 "모든 발화" 옵션이 활성화되어 있음
- 또는 "기본 블록"으로 설정되어 있음

❌ **잘못된 설정**:
- 발화 패턴이 등록되어 있고 "모든 발화" 옵션이 비활성화됨
- 특정 발화 패턴만 등록되어 있음

## 발화 패턴 추가 (선택사항)

### 언제 사용하나?

- 특정 발화 패턴만 이 블록으로 연결하고 싶을 때
- 다른 블록과 구분하고 싶을 때

### 단계별 설정

#### 1단계: 발화 패턴 입력

1. **발화 패턴 입력 필드**에 발화 입력
   - 예: `골드`
2. **추가** 버튼 클릭 또는 **Enter** 키
3. 발화 패턴이 목록에 추가됨

#### 2단계: 추가 발화 패턴 입력

1. 필요한 발화 패턴들을 하나씩 추가:
   ```
   골드
   gold
   g
   게임시작
   게임종료
   리더보드
   도움말
   ```
2. 각 발화 패턴은 별도로 추가

#### 3단계: "모든 발화" 옵션 확인

1. 발화 패턴 목록 아래에 있는 **"모든 발화"** 옵션 확인
2. **비활성화**되어 있는지 확인 (체크 해제)
3. 저장

### 결과

- 입력한 발화 패턴과 **정확히 일치**하는 메시지만 이 블록으로 연결
- 일치하지 않는 메시지는 **폴백 블록** 또는 다른 블록으로 연결

## 커맨드 형태 발화 패턴

### 슬래시 커맨드 (`/`)

**발화 패턴 예시**:
```
/골드
/gold
/g
/게임시작 모험
/리더보드
/도움말
```

**주의**: 
- 발화 패턴은 **정확히 일치**해야 함
- `/골드`와 `골드`는 다른 발화 패턴
- 모든 슬래시 커맨드를 등록하려면 많은 발화 패턴이 필요함

### @봇이름 커맨드 (`@`)

**발화 패턴 예시**:
```
@게임봇 골드
@게임봇 게임시작 모험
@게임봇 리더보드
@게임봇 도움말
```

**주의**: 
- 봇 이름이 다르면 각각 등록해야 함
- `@게임봇 골드`와 `@봇이름 골드`는 다른 발화 패턴
- 봇 이름이 변경되면 발화 패턴도 수정 필요

### 권장: 모든 발화로 설정

**커맨드 형태를 발화 패턴으로 등록하지 않아도 됨**

**이유**:
- 스킬 서버에서 `@`와 `/`를 자동으로 파싱하여 처리
- "모든 발화"로 설정하면 모든 커맨드 형태가 자동으로 작동
- 설정이 간단하고 유지보수가 쉬움

**결과**:
- ✅ `/골드` 작동
- ✅ `@게임봇 골드` 작동
- ✅ `골드` 작동
- ✅ `/게임시작 모험` 작동
- ✅ `@게임봇 게임시작 모험` 작동
- ✅ `게임시작 모험` 작동

## 게임봇 권장 설정

### 최소 설정 (가장 간단)

**"게임봇 메인 블록" 설정**:

1. **사용자 발화**:
   - 발화 패턴 입력 필드: **비워두기**
   - 발화 패턴 목록: **비우기**
   - "모든 발화" 옵션: **활성화** (있는 경우)

2. **파라미터 설정**:
   - 일반 파라미터: 설정 안 함
   - 필수 파라미터: 설정 안 함

3. **응답 설정**:
   - 스킬 연결: **"게임봇 스킬"** 선택

4. **저장 및 배포**

**결과**: 
- ✅ 모든 메시지가 스킬 서버로 전달됨
- ✅ 폴백 블록 문제 없음
- ✅ 새로운 명령어 추가 시 시나리오 수정 불필요
- ✅ Quick Replies 버튼이 응답과 함께 자동으로 표시됨

## 문제 해결

### 문제 1: 여전히 폴백 블록으로 연결됨

**원인**: 
- "모든 발화" 옵션이 제대로 활성화되지 않음
- 발화 패턴이 남아있음

**해결**:
1. 모든 발화 패턴 삭제
2. "모든 발화" 옵션 명시적으로 활성화
3. 저장 및 배포

### 문제 2: 특정 발화만 연결됨

**원인**: 
- 발화 패턴만 등록되어 있고 "모든 발화" 옵션이 비활성화됨

**해결**:
1. 발화 패턴 모두 삭제
2. "모든 발화" 옵션 활성화
3. 저장 및 배포

### 문제 3: "모든 발화" 옵션을 찾을 수 없음

**원인**: 
- 카카오 챗봇 관리자센터 버전에 따라 UI가 다를 수 있음

**해결**:
1. 발화 패턴을 모두 삭제하고 저장
2. 또는 "기본 블록"으로 설정
3. 또는 발화 패턴 입력 필드를 비워두고 저장

### 문제 4: 커맨드 형태가 작동하지 않음

**원인**: 
- 발화 패턴이 정확히 일치하지 않음
- 스킬 서버에서 파싱 오류

**해결**:
1. "모든 발화"로 설정 (권장)
2. 또는 모든 커맨드 형태를 발화 패턴으로 등록
3. 스킬 서버 로그 확인
