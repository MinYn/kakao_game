# 커맨드 방식 구현 가이드

카카오톡 챗봇에서 발화 방식이 아닌 커맨드 방식으로 구현하는 방법을 설명합니다.

---

## 현재 구현 방식 (추천) ⭐

**다른 API 불필요!** 현재 사용 중인 카카오 챗봇 관리자센터 스킬 서버로 커맨드 방식이 가능합니다.

### 이미 구현된 커맨드 방식

#### 1. 슬래시 커맨드 (`/`)

**사용 예시**:
- `/골드` → 골드 조회
- `/게임시작 모험` → 모험 게임 시작
- `/리더보드` → 리더보드 조회

**구현 방식**:
- 스킬 서버에서 메시지를 파싱하여 `/`로 시작하는 경우 처리
- `game_engine.py`에서 자동으로 파싱

#### 2. @봇이름 커맨드 (`@`)

**사용 예시**:
- `@게임봇 골드` → 골드 조회
- `@게임봇 게임시작 모험` → 모험 게임 시작

**구현 방식**:
- 스킬 서버에서 `@`로 시작하는 메시지를 파싱
- 봇 이름 부분을 제거하고 명령어만 추출

#### 3. Quick Replies 버튼

**사용 예시**:
- 봇 멘션(`@게임봇`) 시 버튼 표시
- 버튼 클릭으로 명령어 자동 전송

**구현 방식**:
- 스킬 서버 응답에 `quickReplies` 필드 포함
- 카카오톡에서 자동으로 버튼 표시

---

## 현재 방식의 장점

✅ **완전 무료**: 카카오 챗봇 관리자센터 무료 기능 사용
✅ **API 제한 없음**: 제한 없음
✅ **구현 간단**: 추가 API 불필요
✅ **다양한 커맨드 지원**: `/`, `@`, 버튼 모두 지원

---

## 다른 API 옵션 (고급)

더 고급 기능이 필요하다면 다음 API를 사용할 수 있습니다:

### 1. 카카오톡 채널 API

**용도**:
- 봇이 사용자에게 직접 메시지 전송 (사용자 발화 없이)
- 더 복잡한 메시지 템플릿 사용
- 사용자 정보 조회

**제한사항**:
- 유료일 수 있음
- API 키 필요
- 더 복잡한 설정 필요

**사용 시나리오**:
- 봇이 주도적으로 메시지 전송
- 푸시 알림 기능
- 사용자 프로필 정보 활용

**현재 방식과의 차이**:
- 현재: 사용자 메시지 → 스킬 서버 → 응답
- 채널 API: 봇이 직접 메시지 전송 가능

### 2. 카카오톡 비즈니스 API

**용도**:
- 비즈니스 채널 관리
- 고객 관리
- 마케팅 기능

**제한사항**:
- 비즈니스 계정 필요
- 유료일 수 있음
- 게임봇 용도와는 맞지 않을 수 있음

## 커맨드 방식 구현 방법

### 방법 1: 현재 방식 활용 (권장) ⭐

**설정**:
1. 카카오 챗봇 관리자센터에서 "모든 발화" 활성화
2. 스킬 서버에서 메시지 파싱하여 커맨드 처리

**이미 구현됨**:
- `/골드`, `/게임시작 모험` 등 슬래시 커맨드
- `@게임봇 골드` 등 @봇이름 커맨드
- Quick Replies 버튼

**코드 예시** (`game_engine.py`):
```python
# 슬래시 커맨드 처리
if message.startswith('/'):
    message = message[1:].strip()  # "/골드" → "골드"

# @봇이름 커맨드 처리
elif message.startswith('@'):
    parts = message[1:].split(None, 1)
    if len(parts) > 1:
        message = parts[1].strip()  # "@게임봇 골드" → "골드"
```

### 방법 2: 카카오톡 채널 API 사용 (고급)

**필요한 것**:
- 카카오 개발자 계정
- REST API 키
- 채널 API 권한

**구현 예시**:
```python
import requests

# 카카오톡 채널 API로 메시지 전송
def send_message(user_id: str, message: str):
    url = "https://kapi.kakao.com/v2/api/talk/memo/default/send"
    headers = {
        "Authorization": f"Bearer {ACCESS_TOKEN}",
        "Content-Type": "application/x-www-form-urlencoded"
    }
    data = {
        "template_object": json.dumps({
            "object_type": "text",
            "text": message,
            "link": {
                "web_url": "https://example.com"
            }
        })
    }
    response = requests.post(url, headers=headers, data=data)
    return response.json()
```

**장점**:
- 봇이 주도적으로 메시지 전송 가능
- 더 복잡한 메시지 템플릿 사용 가능

**단점**:
- API 키 필요
- 유료일 수 있음
- 설정이 복잡함

## 권장 사항

### 게임봇 용도라면: 현재 방식 사용 ⭐

**이유**:
- 완전 무료
- 커맨드 방식 이미 지원 (`/`, `@`, 버튼)
- 설정이 간단
- API 제한 없음

**현재 구현된 커맨드**:
- ✅ `/골드` - 슬래시 커맨드
- ✅ `@게임봇 골드` - @봇이름 커맨드
- ✅ Quick Replies 버튼 - 버튼 클릭으로 명령어 전송

### 채널 API가 필요한 경우

**사용 시나리오**:
- 봇이 주도적으로 알림 전송 (예: "게임 시작 시간 알림")
- 사용자 프로필 정보 활용
- 더 복잡한 메시지 템플릿 필요

**주의사항**:
- API 키 발급 필요
- 유료일 수 있음
- 추가 개발 필요
