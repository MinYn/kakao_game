# 성공률 · 비용 · 아슬아슬

## 성공률이 오르는 때

- 우주선이 세질수록 (등급·본체 단계)  
- **센서** 부품이 쌓일수록  
- 강화를 **연속으로 실패**했을수록 (잠깐 보정)  

너무 오르면 상한 근처에서 멈춥니다.  
버튼에 `다시 72%`처럼 보이면 그게 힌트입니다.

## 아슬아슬 (실패인데 안 깎임)

실패 판정이어도, **거의 성공할 뻔**했으면 단계가 안 깎입니다.

연출: `⚠️ 아슬아슬 버팀!`

**장갑** 부품이 있으면, 실패해도 버틸 확률이 조금 더 붙습니다.

## 아슬아슬 성공 (성공인데 더 줌)

성공이지만 아슬아슬하게 붙었을 때, 이름 붙은 축하와 보너스 골드가 나옵니다.

예:

- 🌠 초신성 점화 — 제일 아슬아슬, 보너스 큼  
- ⚡ 플라즈마 오버드라이브 — 중간  
- ✨ 스파크 세리머니 — 살짝 아슬  

## 언제 강화를 누르나

| 상황 | 추천 |
|------|------|
| 성공률 높고, 비용이 보유 골드의 일부만 | 해보자 |
| +5, +10 직전 | 목표로 도전 가치 있음 |
| 성공률 낮거나 올인 직전 | 출동으로 돈·성장 더 모으기 |
| 연패 중이라 보정이 쌓임 | 한 번 더 노려볼 만 |

**전 재산 올인 강화**는 재미는 있지만, 실패 시 타격이 큽니다.
