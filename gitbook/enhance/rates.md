# 성공률 · 비용 · near-miss

## 강화 성공률

강화는 활동 기본 80% 축에 스탯·센서를 얹습니다.

```text
성공률 = min( 80 + 등가스탯×2 + 센서보너스 + 강화pity , 98 )
하한 25
```

- 등가 스탯이 오를수록 (등급↑ 또는 +N↑) 성공률↑  
- 강화 pity: 연속 실패 × 2%p, 최대 12%p  

버튼 라벨 `다시 72%` 가 곧 다음 시도 대략치입니다.

## near-miss (아슬아슬)

실패 판정이어도:

```text
0 < (roll - 성공률) ≤ 5.0  → 아슬아슬 버팀 (본체 유지)
```

또는 **장갑 파츠** 패시브로 일정 확률 세이브 (최대 반영 25%p 캡).

연출: `⚠️ 아슬아슬 버팀!`

## 축하 (아슬아슬 성공)

성공이지만 성공선에 **매우 가까웠을 때** 보너스:

| 이름 | 여유(margin) | 보너스 배율(비용 대비) |
|------|--------------|------------------------|
| 초신성 점화 🌠 | ≤0.5 | ×0.50 |
| 플라즈마 오버드라이브 ⚡ | ≤1.5 | ×0.30 |
| 스파크 세리머니 ✨ | ≤3.0 | ×0.15 |

최소 보너스 골드 10G.

## 언제 강화를 눌러야 하나

| 상황 | 추천 |
|------|------|
| 성공률 ≥ 85%, 비용이 보유 골드의 30% 이하 | 적극 |
| 성공률 70~85%, 마일스톤 직전 | 도전 가치 |
| 성공률 < 70% 또는 올인 비용 | 출동으로 스탯·골드 확보 후 |
| 연패로 pity 쌓임 | 한 번 더 노려볼 만 |

**올인 강화**는 재미는 있지만, 본체 -1 구간에서는 기대값이 급락할 수 있습니다.
