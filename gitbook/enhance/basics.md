# 강화 기본

**강화 1회 = 본체 +N 시도 1번 + (성공 시) 파츠 랜덤 +1.**

## 진입 경로

- 출동 결과 → `강화` 버튼 (성공률 힌트)  
- 홈 → 성장 → 강화  
- 텍스트 `강화`

## 비용

```text
비용 = max( 40 × 1.4 ^ (현재 본체+N) , 10 )
```

| 본체 | 대략 비용 |
|------|-----------|
| +0 | 40G |
| +1 | 56G |
| +2 | 78G |
| +3 | 110G |
| +5 | ~215G |
| +10 | ~1150G |

(반올림·정수화로 실제 UI와 1G 단위 차이 가능)

골드가 부족하면 강화 대신 **출동** CTA가 의미 있습니다.

## 성공 시

1. 본체 +1  
2. 파츠(엔진/센서/장갑) 중 **랜덤 1종 +1**  
3. 아슬아슬 성공이면 **축하 보너스 골드**  
4. +5/+10/… 이면 **마일스톤**  

## 실패 시

1. near-miss 또는 장갑 세이브 → **본체 유지**  
2. 그 외 & 본체>0 → **본체 -1**  
3. 본체 0 → 레벨만 유지, 골드만 소모  
4. 강화 pity 스택 +1

