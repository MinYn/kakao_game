# 강화 하는 법

**강화 한 번 = 내 우주선 본체를 한 단계 올리려는 시도.**

성공하면:

- 본체 단계 +1 (예: +3 → +4)  
- 부품(엔진·센서·장갑) 중 **랜덤 하나** +1  

## 어디서 눌러?

- 출동 결과 화면의 **강화**  
- 홈 → **성장** → **강화**  
- 채팅에 `강화`

## 비용 느낌

단계가 올라갈수록 **기하급수적으로** 비싸집니다.

| 본체 대략 | 비용 감 |
|-----------|---------|
| +0 | 싸다 (수십 G) |
| +3~+5 | 신경 쓰이기 시작 |
| +10 근처 | 꽤 부담 |
| 그 이상 | 출동으로 오래 모아야 함 |

성장 메뉴에 **다음 비용**과 **성공률**이 보이니, 보고 결정하면 됩니다.

골드가 부족하면 강화 대신 **출동**으로 돌아가세요.

## 성공하면

1. 본체 +1  
2. 부품 하나 +1  
3. 아슬아슬 성공이면 **축하 보너스 골드**  
4. +5, +10 같은 구간이면 **특별 연출 + 추가 골드**  

## 실패하면

1. **아슬아슬** 또는 장갑 덕분에 → 단계는 유지  
2. 그 외 → 본체 단계 -1 (0이면 그대로)  
3. 연패하면 다음 강화가 조금 쉬워짐  

## 성장 메뉴에서 볼 것

```text
강화비용 ***G
성공률 **%
골드 ***G
```

성공률이 **숨겨져 있지 않습니다.**  
보고 도전하세요.
