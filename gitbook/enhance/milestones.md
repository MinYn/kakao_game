# +5, +10 같은 구간 보상

본체가 특정 단계에 도달하면 축하가 크게 납니다.

**+5, +10, +15, +20, +25, +30**

```text
⬆️ 마일스톤 +N
배지 단계 올라감 · 보너스 골드
```

## 배지 그림이 바뀌는 구간

본체 단계에 따라 배지가 더 화려해집니다.

| 본체 | 배지 느낌 |
|------|-----------|
| 0~4 | 기본 |
| 5~14 | 한 단계 업 |
| 15~29 | 더 업 |
| 30 이상 | 최고 구간 |

## 공략 포인트

- +4 → +5, +9 → +10 은 **오늘 목표**로 잡기 좋습니다.  
- 직전에서 실패해 -1 되면 아쉽지만, 연패 보정 보고 다시 도전.  
- 정산으로 본체를 0으로 돌려도 **부품·등급**은 남습니다.
