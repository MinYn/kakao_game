# 출동이란?

**출동 한 번 = 우주로 한 판 다녀오기.**

이게 이 게임의 메인 콘텐츠입니다.

## 한 판 흐름

```text
출동 누름
  → (구조 판이면) 패스 1장 씀
  → 성공할지 주사위
  → 성공: 골드 + (가끔 우주선) + (가끔 보너스 아이템)
  → 실패: 위로 골드 + “다음에 조금 더 잘 됨”
  → 결과 화면 → 다시 출동 / 강화
```

## 성공이 잘 되는 조건 (감으로)

- 우주선이 셀수록 (등급·강화) 성공이 잘 됨  
- **센서** 부품이 있으면 특히 정찰이 편해짐  
- 출동을 **여러 번 실패**하면, 다음 판이 조금 쉬워짐 (위로 보정)  
- 너무 높이지는 않고, 대략 **최대 98%** 근처에서 멈춤  

## 골드는 어떻게 나오나

성공하면 기본 골드가 나오고, 우주선이 셀수록 조금 더 붙습니다.  
가끔은 **1.5~2배**처럼 크게 터지기도 합니다.  
**엔진** 부품은 탐사 보상에 도움이 됩니다.

자세한 구간 숫자는 [확률·보상 한눈에](../reference/numbers.md) 참고.

## 왜 출동을 제일 많이 하냐

- 입장료가 없음 (공짜로 굴릴 수 있음)  
- 골드·우주선·패스가 **출동에서만** 나옴  
- 실패해도 완전 빈손 아님  

강화는 “여유 있을 때 스릴”로 끼우면 됩니다.
