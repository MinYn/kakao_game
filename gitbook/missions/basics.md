# 출동 기본

**출동 한 번 = 랜덤 임무 한 판.**

## 흐름

```text
출동 탭
  → (구조면) 패스 1장 소모 시도
  → 성공률 판정
  → 성공: 골드 + (기체?) + (득템?) + (탐사면 패스?)
  → 실패: 구조금 + pity 스택
  → DETAIL 결과 + [다시 출동][강화]
```

## 성공률에 들어가는 것

대략:

```text
성공률 = min( 활동 기본% + 등가스탯×2 + 센서 보너스 + 출동 pity , 98% )
하한 25%
```

- **등가 스탯** = 등급 base + 본체 +N (F+100 ≈ E+1 동일)  
- **센서 파츠**: 정찰에 풀 반영, 다른 활동은 절반  
- **pity**: 연속 실패마다 +3%p (최대 +15%p)

## 보상 스케일

성공 골드 ≈ `(기본 + 랜덤 구간) × (1 + 스탯 배율) × (엔진 보너스)`

- 가끔(약 8%) **1.5~2.0배** 피크 배수  
- 주 엔진 파츠는 **탐사** 보상에 더 큼  

정확한 구간은 [임무 타입](types.md) · [수치 요약](../reference/numbers.md) 참고.

## 왜 출동이 메인인가

- 강화보다 **기대 골드 안정**  
- 기체·패스·득템이 **출동에만** 붙음  
- 실패해도 구조금 → 심리 이탈 적음  

강화는 “남는 골드 + 자신 있는 성공률”일 때 끼워 넣으세요.
