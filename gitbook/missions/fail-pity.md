# 실패 · pity · 구조금

## 실패해도 골드가 온다

출동 실패 시:

- **구조금** 기본 3~8G (+ 연속 실패에 따라 소폭 증가)  
- **mission_fail_streak** +1  
- 다음 출동 성공률에 **pity** 가산  

```text
pity = min( 연속실패 × 3.0%p , 15%p )
```

예: 3연속 실패 → 다음 판 +9%p (캡 15).

성공하면 streak는 **0으로 리셋**.

## 공략적으로 쓰기

1. **연패 구간**에서는 굳이 멈추지 말고 한두 판 더 — pity가 쌓여 있습니다.  
2. 결과 화면의 `pity +N%` 줄을 보면 지금 보너스를 알 수 있습니다.  
3. 구조금은 작지만 “완전 무보상”을 막아주므로, 심리적 스톱을 줄이는 장치입니다.

## 강화 pity와의 차이

| | 출동 | 강화 |
|--|------|------|
| 연속 실패당 | +3%p | +2%p |
| 캡 | 15%p | 12%p |
| 실패 시 기타 | 구조금 | 본체 -1 또는 near-miss 유지 |

자세한 강화 실패는 [성공률 · near-miss](../enhance/rates.md).
