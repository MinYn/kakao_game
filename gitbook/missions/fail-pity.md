# 실패해도 괜찮은 이유

## 실패 = 완전 꽝이 아님

출동이 실패하면:

1. **위로 골드**가 조금 들어옴 (대략 몇 G)  
2. “연속 실패”가 쌓임  
3. **다음 출동이 살짝 쉬워짐**

연패가 길수록 보정이 커지고, 어느 정도 가면 더 안 올라갑니다.  
한 판 성공하면 보정은 리셋됩니다.

결과 화면에 `pity +N%` 비슷한 줄이 보이면  
“지금 조금 유리하다”는 뜻으로 보면 됩니다.

## 플레이할 때

1. **두세 번 졌다고 끄지 마세요.** 다음이 조금 편해져 있습니다.  
2. 위로 골드로 강화 비용 일부를 메울 수 있습니다.  
3. 일일 출동 목표도 실패 판으로 채울 수 있습니다.

## 강화 실패와 비교

| | 출동 실패 | 강화 실패 |
|--|-----------|-----------|
| 골드 | 위로금 받음 | 비용은 이미 나감 |
| 성장 | 보통 그대로 | 단계가 깎일 수 있음 |
| 연패 보정 | 있음 | 있음 (강화용) |

강화의 아슬아슬·하락은 [성공률 · 아슬아슬](../enhance/rates.md) 참고.
