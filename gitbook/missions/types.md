# 정찰 · 탐사 · 구조

출동 시 아래 셋 중 하나가 **가중 랜덤**으로 고릅니다.  
구조는 **패스가 있을 때만** 후보에 들어갑니다.

## 비교표

| | 정찰 🛰️ | 탐사 🧭 | 구조 🚨 |
|--|---------|---------|---------|
| 가중치 (대략) | 50 | 35 | 15 |
| 패스 있을 때 비중 | ~50% | ~35% | ~15% |
| 패스 없을 때 | 정찰+탐사만 | (비율 재정규화) | 등장 안 함 |
| 기본 성공률 | 86% | 78% | 64% |
| 기본 보상대 | 낮음 | 중간 | 높음 |
| 기체 발견율 | 8% | 18% | 35% |
| 특수 | — | 패스 드랍 30% | 패스 1장 소모 |

## 정찰

- 가장 자주 나옴 → **안정 파밍**  
- 센서 파츠 효과가 가장 큼  
- 신규 기체 기댓은 낮음  

## 탐사

- 골드·발견 균형  
- **구조 패스**를 주는 거의 유일한 길 (성공 시 30%)  
- 엔진 파츠 보너스 큼  

## 구조

- 고위험 고보상 + **최고 발견율**  
- 패스 없으면 출동 풀에서 제외  
- 패스 부족 화면이 뜨면 탐사를 노리며 출동 연타  

## 패스 루프

```text
출동 (탐사 당첨) → 성공 → 30%로 패스 +1
     ↓
패스 보유 시 출동 풀에 구조 포함
     ↓
구조 당첨 시 패스 -1 → 대량 골드 / 기체 노림
```

초보는 패스를 **모아 두지 말고 자연 소모**해도 됩니다.  
도감 후반(고등급)에서는 구조 비중을 의식하는 편이 이득입니다.
