# 정찰 · 탐사 · 구조 차이

출동을 누르면 아래 셋 중 **하나가 랜덤**으로 골라집니다.  
직접 “정찰만 고르기”는 없습니다.

**구조**는 **패스가 있을 때만** 후보에 들어갑니다.

## 한눈에 비교

| | 정찰 🛰️ | 탐사 🧭 | 구조 🚨 |
|--|---------|---------|---------|
| 나오는 빈도 | 제일 자주 | 중간 | 가끔 (패스 있을 때) |
| 난이도 | 쉬움 | 보통 | 어려움 |
| 보상 | 소소 | 괜찮음 | 큼 |
| 새 우주선 기대 | 낮음 | 중간 | 높음 |
| 특별함 | 안정 파밍 | **패스 얻기** | 패스 1장 소모 |

대략 비율(패스 있을 때): 정찰 절반 · 탐사 1/3 조금 넘음 · 구조 소수.

## 정찰

- 자주 나와서 **골드 갈무리**에 좋음  
- 센서 부품 효과가 잘 느껴짐  
- 희귀 우주선은 기대 낮음  

## 탐사

- 골드와 발견의 중간  
- 성공하면 **구조 패스**가 나올 수 있음 (꽤 자주)  
- 엔진 부품이 있으면 이득  

## 구조

- 위험하지만 보상·우주선 기대 큼  
- 패스 없으면 출동 풀에 안 섞임  
- “패스 부족”이 뜨면 탐사가 나올 때까지 출동을 더  

## 패스로 도는 재미

```text
출동 → 탐사 당첨 → 성공 → 패스 얻을 수도
      → 패스 있으면 구조도 섞임
      → 구조 당첨 시 패스 1장 씀 → 대박 노림
```

초보는 패스를 **꽁꽁 모을 필요 없습니다.**  
자연스럽게 쓰이면서 배우면 됩니다.  
도감을 열심히 채울 때가 되면 구조를 의식하면 좋아요.
