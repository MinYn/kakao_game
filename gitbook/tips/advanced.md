# 중·고수 루프

## 세션 템플릿 (15~20분)

```text
1) 홈 — 일일/기체 확인
2) 출동 블록 10~20회 (결과 CTA 연타)
3) 성공률·비용 보고 강화 블록 3~8회
4) 도감 목록 — 빈칸·중복 확인
5) (선택) 정산 후 재가속 or 종료
```

## 등급 레이스

- 저등급 구간: 출동 물량으로 F/E 채우기  
- 패스 루프 의식: 탐사→패스→구조 비중  
- 상위 계승 후: 본체 숫자가 낮아져 **강화 비용이 싸지는 타이밍**에 집중 강화  

## 파츠 장기 자산

정산으로 본체를 리셋해도 파츠는 남습니다.

- 센서 누적 → 전 구간 성공률 바닥 상승  
- 장갑 누적 → 강화 시도 심리 부담↓  
- 엔진 누적 → 탐사 히트 시 페이오프↑  

고수일수록 **파츠 총합**이 숨은 MMR.

## 위험 관리

| 신호 | 행동 |
|------|------|
| 강화 연패 2+ | pity 확인 후 1회 더 or 출동 복귀 |
| 본체 고점 + 비용 폭발 | 정산 검토 or 출동만 |
| 골드 고갈 | 출동만, 강화 버튼 무시 |
| S 근접 감정 | 구조 패스 저축 vs 즉시 사용 선택 |

## 리더보드

랭킹은 루프 밖 동기. 상태/홈 근처에서 가끔 확인만.  
일일 출동·강화 목표를 먼저 깨는 편이 세션 만족도가 높습니다.
