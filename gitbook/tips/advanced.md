# 좀 익숙해진 뒤 루틴

## 15~20분 세션 예시

```text
1) 홈 — 오늘 목표·기체 확인
2) 출동 10~20번 (결과에서 연타)
3) 성공률·비용 보고 강화 몇 번
4) 도감 — 빈칸·중복 확인
5) (선택) 정산 후 다시 키우기 or 종료
```

## 등급을 올리고 싶을 때

- 초반: 출동 물량으로 F/E 채우기  
- 중반: 패스 → 구조 섞이는 구간 즐기기  
- 상위 교체 직후: 본체 숫자가 낮아져 **강화비가 싸진 타이밍**에 몰아 강화  

## 부품은 장기 자산

본체를 정산해도 부품은 남습니다.

- 센서 → 전반적으로 성공 편해짐  
- 장갑 → 강화가 덜 무서울  
- 엔진 → 탐사 대박 때 더 달콤  

오래 한 사람일수록 부품 총합이 숨은 실력입니다.

## 위험 관리

| 신호 | 행동 |
|------|------|
| 강화 연패 | 보정 보고 한 번 더, 아니면 출동 복귀 |
| 비용 폭발 | 정산 검토 또는 출동만 |
| 골드 바닥 | 강화 버튼 무시, 출동만 |
| S 욕심 | 패스 저축 vs 바로 쓰기 — 취향 |

## 랭킹

가끔 보면 동기 부여는 됩니다.  
다만 **오늘 출동·강화 목표**를 먼저 깨는 편이 기분 좋습니다.
