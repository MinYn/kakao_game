# 초보 로드맵

## 세션 0 (첫 10분)

1. 홈에서 **출동 ×5** (일일 목표)  
2. 뜨는 결과에서 **다시 출동**만 연타  
3. 골드 200~ 모이면 **강화 2~3회**  
4. 홈에서 일일 줄 확인 후 종료해도 OK  

이 단계 목표: UI·CTA에 익숙해지기. 등급은 신경 쓰지 말 것.

## 세션 1 (본체 +5)

1. 출동 위주, 성공률 높은 구간에서만 강화  
2. **+5 마일스톤** 찍기 → 배지 stage 1  
3. 도감 목록에서 F급 빈칸 확인  

## 세션 2 (패스·탐사 감각)

1. 탐사 당첨 시 패스 드랍 주목  
2. 패스 생기면 구조가 섞임 → 보상·발견 기댓값↑  
3. NEW 뜨면 계승 문구 읽기  

## 하지 말아야 할 것

- 골드 전액 올인 강화 (한 번에)  
- 실패 두 번에 로그아웃 종료 (pity 버림)  
- 홈만 들락날락 (결과 CTA를 무시)  
- 정산 스팸으로 파츠 기대 (파츠는 안 팔림 — 본체만 리셋)
