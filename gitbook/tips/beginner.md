# 초보 추천 순서

## 첫 10분

1. 홈에서 **출동 5번** (오늘 목표)  
2. 결과 화면에서 **다시 출동**만 연타  
3. 골드가 생기면 **강화 2~3번**  
4. 홈에서 오늘 목표 확인하고 쉬어도 OK  

목표: 버튼 감 익히기. 등급은 아직 신경 안 써도 됩니다.

## 그다음 세션

1. 출동 위주, 여유 있을 때만 강화  
2. 본체 **+5** 찍어 보기 (구간 축하)  
3. 도감 목록에서 F 빈칸 확인  

## 패스가 보이기 시작하면

1. 탐사 성공 때 패스 드랍 주목  
2. 패스 있으면 구조가 섞임 → 보상·우주선 기대↑  
3. NEW 뜨면 교체 문구만 읽어 보기  

## 하지 말았으면 하는 것

- 전 재산 한 방에 강화  
- 두 번 실패하고 바로 끄기 (다음이 조금 유리해짐)  
- 결과 화면 무시하고 홈만 들락날락  
- 정산 스팸으로 부품 기댓값 올리기 (부품은 정산과 무관)
