# 골드 효율

## 수입 우선순위 (체감)

1. **출동 성공 기본급** — 횟수 = 기대 수입  
2. **출동 피크 배수 (8%)** · 득템 — 운, 횟수로 흡수  
3. **중복 분해** — 발견이 날 때마다 바닥 수입  
4. **강화 축하/마일스톤** — 가끔  
5. **정산** — 저축 인출 (이자는 아님)

## 지출

| 지출 | 성격 |
|------|------|
| 강화 비용 | 성장 투자, 실패 시 일부 매몰 |
| (없음) 출동 입장료 | 출동 자체 비용 없음 |

출동은 **공짜 롤**에 가깝습니다. 강화만 골드 싱크.

## 간단 규칙

```text
보유 골드 ≥ 다음 강화 비용 × 3  → 강화 여유
보유 골드 < 다음 강화 비용 × 1.5 → 출동 우선
```

마일스톤 직전(+4, +9…)만 예외적으로 공격적으로.

## 정산 타이밍

- 본체만 높고 파츠·등급은 유지하고 싶을 때  
- 비용 곡선이 부담될 때 “리셋 후 재가속”  
- 환수율 100%가 아님을 알고 쓸 것  

## 실패 구조금

작지만 **연타 유지 비용**을 낮춥니다.  
“실패한 판 = 0”이 아니므로, 기댓값을 계산할 때 완전히 버리지 마세요.
