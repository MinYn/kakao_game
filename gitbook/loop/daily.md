# 오늘의 미니 목표

홈 화면에 이런 줄이 있습니다.

```text
📅 출동 2/5  강화 1/3
```

| 목표 | 기본 | 의미 |
|------|------|------|
| 출동 | 5번 | 오늘 최소 출동 횟수 |
| 강화 | 3번 | 오늘 최소 강화 시도 |

## 플레이 팁

- **시간이 없을 때:** 출동 5 + 강화 3만 해도 충분합니다.  
- **실패한 출동도 횟수에 들어갑니다.** 위로 골드 받으면서 채우세요.  
- **강화도 성공/실패 모두 횟수에 들어갑니다.**  
- 날짜가 바뀌면 숫자는 다시 0부터입니다.

## 3분 루틴 예시

1. 홈에서 오늘 목표 확인  
2. 출동 5번 (결과에서 바로 다시 출동)  
3. 강화 2~3번  
4. 홈에서 `5/5`, `3/3` 보고 종료  

더 놀고 싶으면 그 위에 출동을 더 얹으면 됩니다.
