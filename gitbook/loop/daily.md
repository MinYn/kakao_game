# 일일 목표

홈 화면 한 줄:

```text
📅 출동 N/5 강화 M/3
```

| 목표 | 기본값 | 의미 |
|------|--------|------|
| 출동 | 5회 | 짧은 루프 최소 바퀴 |
| 강화 | 3회 | 성장 피크 최소 노출 |

## 플레이 팁

- **접속이 짧을 때:** 출동 5 → 강화 3만 해도 “오늘 분량” 완료 감각.  
- **실패 출동도 카운트**됩니다. 구조금 받으면서 목표를 채우세요.  
- **강화 시도**도 카운트 (성공/실패 모두). 골드가 빠듯하면 저강화(+0~+2)에서 시도.  
- 날짜가 바뀌면 카운터는 리셋됩니다 (세션 기준 일일 버킷).

## 추천 루틴 (3분)

1. 홈 확인 → 일일 줄 보기  
2. 출동 5회 (결과에서 재탭)  
3. 강화 2~3회  
4. 홈에서 `5/5`, `3/3` 확인 후 종료  

길 세션이면 그 위에 [중·고수 루프](../tips/advanced.md)를 얹으면 됩니다.
