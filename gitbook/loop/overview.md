# 한 줄 루프 이해

## 짧은 루프 (~30초)

```text
출동 → 성공/실패/득템/기체? → 골드↑ → 강화 유혹 → 재탭
```

1. **출동**으로 가변 보상 (메인 도파민)  
2. 결과에서 골드·발견을 확인  
3. 버튼으로 **다시 출동** 또는 **강화**  
4. 강화가 비싸지거나 쫄리면 다시 출동  

이 사이클을 끊지 않는 것이 공략의 전부입니다.

## 중간 루프 (세션)

- 본체 **+5 / +10 / +15…** 마일스톤  
- 상위 등급 기체 임박 / 계승  
- 도감 빈칸 (`???`) 메우기  

## 긴 루프 (수집)

- 등급 **F → S**  
- 파츠 +N 쌓기  
- 배지 비주얼 stage 0→3  

## 역할 분리 (헷갈리지 말 것)

| 콘텐츠 | 역할 | 비고 |
|--------|------|------|
| 출동 | 메인 보상 엔진 | 연타 가치 최고 |
| 강화 | 하이리스크 피크 | 성공률·비용 공개 |
| 도감 | 수집 피크 | NEW / 중복 모두 가치 |
| 상태·골드 | 대시보드 | 루프 중간에 끼우지 않기 |
| 정산 | 골드 환전 | 본체만 0으로, 파츠·등급 유지 |

## CTA가 말하는 것

출동 직후 `[다시 출동][강화 72%]` 가 뜨면:

- 왼쪽 = **같은 재미 한 번 더**  
- 오른쪽 = **성장 피크 도전** (확률 힌트 포함)

강화 직후 `[다시 80%][출동]` 은 반대로, 위험 루프 vs 안전 파밍 선택입니다.
