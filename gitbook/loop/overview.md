# 기본 흐름 한 장 정리

## 짧은 한 바퀴 (한 30초 느낌)

```text
출동 → 성공/실패/아이템/우주선? → 골드 늘음
     → “강화할까?” → 다시 출동 또는 강화
```

1. **출동**으로 보상 받기 (이 게임의 메인)  
2. 결과 보고  
3. **다시 출동** 하거나, 여유 있으면 **강화**  
4. 강화가 비싸지거나 쫄리면 다시 출동  

이 반복이 전부입니다.

## 조금 더 긴 재미

- 본체 강화가 **+5, +10…** 구간에 도달  
- 더 좋은 등급 우주선 발견  
- 도감 빈칸(`???`) 채우기  

## 오래 하는 재미

- 등급을 F에서 S 쪽으로  
- 부품(엔진·센서·장갑) 차곡차곡  
- 배지 그림이 점점 화려해짐  

## 뭘 중심으로 놀까

| 콘텐츠 | 역할 | 초보 팁 |
|--------|------|---------|
| 출동 | 돈·아이템·우주선 공급 | **제일 많이 누르기** |
| 강화 | 짜릿한 성장 | 여유 골드 있을 때 |
| 도감 | 수집 쾌감 | 가끔 확인 |
| 상태·골드 | 정보 창 | 필요할 때만 |
| 정산 | 본체를 돈으로 바꾸기 | 익숙해진 뒤 |

## 결과 버튼이 말하는 것

출동 직후 `다시 출동` / `강화 72%` 가 보이면:

- 왼쪽 = **같은 재미 한 번 더**  
- 오른쪽 = **성장 도전** (숫자는 대략 성공 확률)

강화 직후 `다시 강화` / `출동` 은  
“한 번 더 도박” vs “안전하게 파밍” 선택입니다.
