# 5분 만에 시작하기

## 1. 게임 열기

디스코드에서 봇이 있는 채널에 말을 걸면 **홈 화면**이 뜹니다.

대략 이런 느낌입니다.

```text
🛰️ 우주 탐험 홈
콜사인 STS-***
기체 (내 우주선)
골드 ***G
📅 출동 0/5  강화 0/3
```

아래 버튼 네 개:

| 버튼 | 뭐 하는 거? |
|------|-------------|
| 🔨 성장 | 강화·정산 메뉴 |
| 🚀 출동 | **한 판 바로 시작** (제일 중요) |
| 📚 도감 | 모은 우주선 보기 |
| 📊 상태 | 내 정보 |

## 2. 처음엔 출동만 연타

홈에서 **출동**을 누르세요.

- 정찰 / 탐사 / 구조 중 **하나가 랜덤**으로 나옵니다.
- 성공하면 골드, 가끔 아이템·우주선.
- 실패해도 **조금 골드**를 줍니다.

결과가 끝나면 버튼이 이렇게 바뀝니다.

| 버튼 | 뜻 |
|------|-----|
| 🚀 다시 출동 | 한 판 더 |
| 🔨 강화 | 지금 성장 도전 (옆에 %가 있으면 성공 확률 힌트) |

**홈으로 돌아갈 필요 없어요.**  
결과 화면에서 바로 또 누르면 됩니다.

## 3. 골드 좀 모이면 강화

출동 결과의 **강화**, 또는 홈 → 성장 → 강화.

- 성공: 본체 강화 단계 +1, 부품 중 하나 +1  
- 아슬아슬 실패: 단계는 안 깎임  
- 그냥 실패: 단계가 1 내려갈 수 있음 (0이면 유지)

강화 결과에서는 **다시 강화** / **출동** 중 고르면 됩니다.

## 4. 오늘 할 일 체크

홈 맨 아래:

```text
📅 출동 3/5  강화 1/3
```

기본 목표는 **출동 5번 · 강화 3번**.  
짧게 접속해도 이만큼만 하면 “오늘 분량” 느낌입니다.
