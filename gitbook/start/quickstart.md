# 5분 빠른 시작

## 1. 봇과 대화 시작

디스코드 채널에서 봇을 멘션하거나 메시지를 보내 게임을 시작합니다.  
첫 화면은 **홈 (D0)** 입니다.

```text
🛰️ 우주 탐험 홈
콜사인 STS-***
기체 (장착 기체 / 기본 셔틀)
골드 ***G
📅 출동0/5 강화0/3
```

하단 버튼 4개:

| 버튼 | 하는 일 |
|------|---------|
| 🔨 성장 | 강화·판매 메뉴 |
| 🚀 출동 | **바로 임무 1회** (원탭 결과) |
| 📚 도감 | 수집 현황 |
| 📊 상태 | 골드·패스·상세 |

## 2. 처음 할 일: 출동 3~5회

홈에서 **출동**을 누릅니다.

- 정찰 / 탐사 / 구조 중 하나가 **랜덤**으로 나옵니다.
- 성공하면 골드, 가끔 득템·기체 발견.
- 실패해도 **구조금**이 조금 들어옵니다.

결과 화면 버튼 (루프 유지):

| 버튼 | 의미 |
|------|------|
| 🚀 다시 출동 | 같은 루프 한 번 더 |
| 🔨 강화 N% | 지금 성공률로 강화 유혹 |

**홈으로 굳이 안 가도 됩니다.** 결과에서 바로 재탭하세요.

## 3. 골드가 모이면 강화 1~2회

출동 결과에서 **강화** 또는 홈 → 성장 → 강화.

- 성공: 본체 +1, 파츠 중 하나 +1
- 아슬아슬 실패: 본체 유지 (near-miss)
- 일반 실패: 본체 -1 (0이면 유지)

강화 결과 버튼: `[다시 강화][출동]`

## 4. 일일 목표 확인

홈 맨 아래 줄:

```text
📅 출동 N/5 강화 M/3
```

기본 목표는 **출동 5 · 강화 3**. 짧게 접속해도 루프를 한 바퀴 돌리기 좋습니다.
