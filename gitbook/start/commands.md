# 말해도 되는 명령어

대부분 **버튼만** 눌러도 됩니다.  
버튼이 없거나 습관적으로 칠 때 참고하세요.

## 자주 쓰는 말

| 치면 | 결과 |
|------|------|
| 홈 | 처음 화면 |
| 출동 | 한 판 시작 |
| 강화 | 성장 1회 |
| 성장 | 강화·정산 메뉴 |
| 도감 | 수집 메뉴 |
| 상태 | 상태 메뉴 |
| 목록 | 도감 자세히 |
| 다음 | 도감 다음 페이지 |
| 정산 또는 판매 | 본체 강화 단계 팔아서 골드 |
| 패스 | 구조용 패스 확인 |
| 골드 | 보유 골드 |
| 도움말 | 간단 설명 |

## 출동 관련 옛말

예전에 쓰이던 말도 **전부 출동과 같게** 동작합니다.

정찰, 탐사, 구조, mission, go …

→ 결국 **랜덤 한 판**입니다. 종류를 직접 고르지 않아요.

## 팁

- 결과 화면에 있는 버튼 글자가 곧 명령입니다.  
- 이상한 말을 치면 보통 **홈**으로 돌아갑니다.
