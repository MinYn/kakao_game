# 명령어 치트시트

버튼과 같은 말을 텍스트로 쳐도 동작합니다.  
대소문자·영어 별칭이 많은 명령은 아래에 모아 둡니다.

## 네비게이션

| 말 | 화면 |
|----|------|
| 홈, home, hub, 시작 | D0 홈 |
| 성장, grow | D1 성장 메뉴 |
| 도감, collection, codex, 수집, ships | D1 도감 |
| 상태, status, info | D1 상태 |
| 목록 | 도감 페이지 |
| 다음 | 도감 다음 페이지 |
| 상세, 상태상세 | 상태 상세 |
| 도움말, help, ?, h | 도움말 |

## 루프 행동

| 말 | 동작 |
|----|------|
| 출동, mission, 탐험, go, m, 0 | 통합 출동 (랜덤 이벤트) |
| 정찰, scout, walk, n, 1 | 출동 alias (동일) |
| 탐사, survey, play, s, 2 | 출동 alias |
| 구조, rescue, challenge, boss, b, 3 | 출동 alias |
| 강화, 업그레이드, 개조, train | 본체 강화 1회 |
| 판매, 정산, sell, 추억, 돌아보기 | 본체 +N 정산 |

> 예전처럼 정찰/탐사/구조를 **직접 고르지 않습니다.**  
> 전부 **출동**으로 들어가며, 안쪽에서 가중 랜덤으로 결정됩니다.

## 확인

| 말 | 동작 |
|----|------|
| 골드, gold, g, 포인트, p, pt… | 골드 |
| 패스, ticket, t | 구조 패스 |
| 리더보드, 랭킹, rank, r… | 랭킹 |

## 팁

- 결과 화면에서는 버튼의 `messageText`가 곧 명령입니다 (`출동`, `강화`).  
- 모르는 말을 치면 **홈**으로 돌아갑니다.
