# 화면이랑 버튼 보는 법

채팅에 맞게 화면이 짧게 잘립니다.  
길게 읽을 필요 없고, **버튼 두세 개만** 보면 됩니다.

## 두 가지 화면 느낌

| 느낌 | 글 줄 수 | 버튼 | 언제 |
|------|----------|------|------|
| 메뉴 | 짧게 (몇 줄) | 4개 | 홈, 성장, 도감, 상태 |
| 결과 | 조금 길게 | 2개 | 출동·강화 끝난 뒤 |

## 어디로 들어가는지

```text
홈
 ├─ 성장 → 강화 / 정산
 ├─ 출동 → 바로 한 판 결과
 ├─ 도감 → 목록 넘기기
 └─ 상태 → 상세 정보
```

## 결과 화면 버튼이 중요한 이유

출동·강화가 끝나면 **홈 대신** 이런 버튼이 뜹니다.

| 방금 한 것 | 버튼 예시 |
|------------|-----------|
| 출동 끝 | 다시 출동 / 강화 |
| 강화 끝 | 다시 강화 / 출동 |
| 정산 끝 | 강화 / 출동 |

의도: **한 판 더** 누르기 쉽게.

홈으로 가고 싶을 때만:

- 메뉴에 있는 **홈** 버튼  
- 채팅에 `홈` 이라고 치기  

## 결과 글은 보통 이 순서

```text
1. 성공/실패 한 줄
2. 골드·단계 같은 숫자
3. 보너스 (아이템, 새 우주선 등)
4. 다음 강화 비용·확률
5. “한 번 더?” 같은 꼬리말
```

이모지 대충 의미:

| 표시 | 뜻 |
|------|-----|
| ✅ | 성공 |
| ❌ | 실패 |
| ⚠️ | 아슬아슬하게 버팀 |
| 🎁 | 보너스 아이템 |
| ⬆️ | 성장 구간 / 상위 교체 |
| 🆕 | 처음 얻는 우주선 |
