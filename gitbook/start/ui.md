# 화면·버튼 가이드

모바일 채팅에 맞춘 **두 가지 레이아웃**만 사용합니다.

| 레이아웃 | 본문 | 버튼 | 쓰임 |
|----------|------|------|------|
| **MENU** | 최대 5줄 × 25자 | 4개 | 홈, 성장, 도감, 상태 |
| **DETAIL** | 최대 15줄 × 25자 | 2개 | 출동/강화/정산 결과, 상세 |

## depth (깊이)

```text
D0  홈 MENU
 └─ D1  성장 / 도감 / 상태 MENU
      └─ D2  결과 DETAIL (출동·강화·정산·골드·패스…)
           └─ D3  도감 추가 페이지
```

- 깊이는 최대 **3**.  
- 결과(D2)에서는 홈 대신 **루프 CTA**가 우선입니다.

## 결과 화면 CTA (중요)

| 화면 | 버튼 1 | 버튼 2 |
|------|--------|--------|
| 출동 결과 | 다시 출동 | 강화 (성공률 % 힌트) |
| 강화 결과 | 다시 강화 (성공률 %) | 출동 |
| 정산 결과 | 강화 | 출동 |
| 그 외 DETAIL | (상황별) | 홈 |

**의도:** “홈 찍고 다시 들어오기” 마찰을 줄여 **30초 루프**를 유지한다.

## 결과 텍스트 슬롯

성공·실패 메시지 순서는 대체로 고정입니다.

```text
1. 훅     ✅ 출동 성공! / ❌ 강화 실패
2. 수치   +골드, 본체 +N, 스탯
3. 보너스 득템, NEW 기체, 마일스톤
4. 진행   다음 강화 비용·성공률
5. CTA    한 번 더 출동? / 다시 도전!
```

이모지 톤: ✅ 성공 · ❌ 실패 · ⚠️ 아슬아슬 · 🎁 득템 · ⬆️ 승급/마일스톤 · 🆕 NEW

## 홈으로 가는 법

- 메뉴 화면(성장·도감·상태)의 **홈** 버튼  
- 상태·골드·패스·도움말 등 비루프 DETAIL의 **홈**  
- 텍스트로 `홈` 입력
