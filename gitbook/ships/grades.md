# 등급 F~S 쉽게 보기

우주선 등급은 알파벳 한 줄입니다.

**F → E → D → C → B → A → S**  
(왼쪽이 흔하고, 오른쪽이 희귀·강함)

![F 등급 느낌](../assets/ship_samples/grade_F.png)
![S 등급 느낌](../assets/ship_samples/grade_S.png)

## 우주선 카드에 있는 것

```text
이름 + 등급 + 본체 단계(+N) + 부품들
```

| 항목 | 쉬운 말 |
|------|---------|
| 등급 | 기체 티어 (F~S) |
| 본체 +N | 강화로 올린 성장 |
| 부품 +N | 엔진·센서·장갑 강화 |

예: `코멧 스카우트 ★F +12`

## 등급이 나올 확률 감

출동에서 우주선이 “발견”될 때, 등급은 대략 이렇게 기울어 있습니다.

| 등급 | 감 |
|------|-----|
| F | 제일 잘 나옴 |
| E, D | 그다음 |
| C, B | 점점 드묾 |
| A, S | 축제급 |

같은 등급 안에서는 그 등급 우주선 중 하나가 나옵니다.

## 상위 등급을 끼면?

전투력(성공·보상)은 **허탈하게 0이 되지 않도록** 맞춰 줍니다.  
자세한 건 [좋은 우주선 얻으면 어떻게 되나](inherit.md).
