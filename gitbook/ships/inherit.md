# 등가 계승 (F+100 ≈ E+1)

상위 등급 기체를 **장착**하면 본체 +N 이 새 등급 기준으로 다시 계산됩니다.  
**파츠 +N 은 그대로** 가져갑니다.

## 언제 발동하나

출동 성공 → 기체 발견 → 아래 중 하나면 장착/계승 메시지:

1. **첫 장착** (아직 주력 없음) — 등급이 다르면 등가 환산  
2. **현재보다 높은 등급** 발견 — 주력 교체 + 계승  

동급·하위 등급은 도감에만 들어가고 주력을 바꾸지 않습니다.

## 환산 직관

| 이전 | 이후 (예) |
|------|-----------|
| F+100 | E+1 |
| F+0 | E+0 근처 (반올림) |
| E+99 | D+1 계열 |

핵심: **스탯 합을 보존**하도록 N을 다시 잡습니다.  
그래서 “상위 기체 = 무조건 스펙 폭등”이 아니라, **성장 궤도를 한 단계 올린 채 유지**에 가깝습니다.

## 결과 문구

```text
⬆️ 계승 F→E+1
```

모바일 한 줄 피크. 상세 수치는 상태 화면에서 확인.

## 공략

- 저등급에서 +N 을 잔뜩 쌓아도, 상위 드랍 시 **허탈하게 0이 되지 않습니다.**  
- 계승 직후 본체 숫자가 작아 보여도 **파워는 유사** — 강화 비용은 “새 +N” 기준이라 다시 싸질 수 있음 → 성장 재가속 타이밍.  
- S급 노림수: 구조 비중↑ (패스 루프) + 출동 횟수.
