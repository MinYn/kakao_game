# 우주 탐험 공략집

디스코드에서 하는 **우주 탐험** 게임 공략입니다.  
어렵게 외울 건 없고, **버튼 누르는 재미**를 오래 가져가도록 정리했어요.

![입문 기체 예시](assets/ship_samples/catalog_comet_scout_F_plus0.png)

## 이 게임, 한 줄로

> **출동**으로 골드·아이템·우주선을 모으고,  
> 남는 골드로 **강화**해서 우주선을 키운다.

| 이거 누르면 | 이런 느낌 |
|-------------|-----------|
| **출동** | 한 판 돌기. 보상 뽑기 메인 |
| **강화** | 도박 느낌 성장. 성공하면 강해짐 |
| **도감** | 모은 우주선 자랑·수집 |
| **상태** | 내 정보 확인 |

## 한 줄 공략

```text
출동 여러 번 → 골드 생기면 강화
실패해도 조금 줌 → 멈추지 말고 한 번 더
좋은 우주선 뜨면 주력 교체 확인
오늘 목표(출동·강화 횟수)만 깨도 OK
```

**완전 꽝은 거의 없습니다.**  
실패해도 위로 골드, 이미 있는 우주선이 또 나와도 분해 골드가 나갑니다.
