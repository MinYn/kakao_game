# NEW랑 중복은 뭐가 좋아?

## NEW (처음 얻는 우주선)

```text
🆕 NEW F급!
💥 코멧 스카우트
```

- 도감 빈칸이 채워짐  
- 조건이 맞으면 주력 장착·교체  

고등급 NEW는 그날 하이라이트입니다.  
구조를 자주 보면 기대가 조금 더 올라갑니다.

## 중복 (이미 있는 우주선)

```text
중복 코멧 스카우트 x2
🎁 분해 +골드
```

이미 있어도 **골드로 바꿔 줍니다.**  
등급이 높을수록 분해 골드가 큽니다.

| 등급 | 분해 골드 감 |
|------|----------------|
| F | 소소 |
| E~C | 점점 괜찮음 |
| B~A | 달콤 |
| S | 축제 |

**“또 나왔네 쓰레기”가 아닙니다.** 돈입니다.

## 우주선이 뜰 확률 감

| 임무 | 발견 기대 |
|------|-----------|
| 정찰 | 낮음 |
| 탐사 | 중간 |
| 구조 | 높음 |

뜬 뒤에 등급 추첨 → 그 등급 기체 중 하나.
