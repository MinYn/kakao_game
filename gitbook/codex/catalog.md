## 목록 UI

```text
📚 도감 1/N
수집 k/10종
주력 …
F a/3
-이름 or -???
…
```

- `★` 표시 = 현재 장착  
- `x2` = 중복 획득 횟수  
- `???` = 미발견  

**다음** 버튼으로 페이지 이동 (depth D2→D3).
